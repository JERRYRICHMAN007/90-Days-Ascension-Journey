# 🚀 Quick Start Guide

## Installation & Setup

1. **Navigate to the react-dashboard folder:**
   ```bash
   cd react-dashboard
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   The app will be available at `http://localhost:5173`

## 📱 Features

- **Dashboard View**: See all 4 journeys at a glance with progress bars
- **Journey Detail Pages**: Click any journey card to see full week-by-week breakdown
- **Week Selector**: Navigate through all 13 weeks easily
- **Day Cards**: Each day shows complete tasks, workouts, readings, etc.
- **Progress Tracking**: Mark days as complete (Premium feature)
- **Local Storage**: Your progress saves automatically

## 🎨 Customization

- **Colors**: Edit CSS files to change gradient colors

- **Features**: Add new premium features in components

## 📦 Build for Production

```bash
npm run build
```

The production files will be in the `dist` folder.
