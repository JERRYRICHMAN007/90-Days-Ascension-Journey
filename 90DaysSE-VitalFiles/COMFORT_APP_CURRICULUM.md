# Comfort App - React Native Mobile Engineering Curriculum

## Overview
This curriculum is designed to prepare for building the Comfort App MVP as specified in the Engineering Services Contract. The focus is on React Native mobile development with supporting backend and admin dashboard skills.

## Contract Requirements Summary

### Product Components
1. **Passenger App (Android/iOS)** - React Native
2. **Driver/Conductor App (Android/iOS)** - React Native  
3. **Admin Console (Web Dashboard)** - ReactJS
4. **Backend APIs + Cloud Infrastructure** - ExpressJS

### Key Features to Build

#### Passenger App Features:
- Live Tracking & Real-Time ETA
- Route Selection (Intra-city + Inter-city)
- Mobile Money Payments (MoMo)
- Booking System (Inter-city only)
- User Account & Preferences

#### Driver App Features:
- Automatic Fare Calculation & Management
- Mobile Money Payment Acceptance
- Route & Availability Management
- Live Location Sharing

#### Admin Dashboard Features:
- Dynamic Pricing Engine
- Driver & Vehicle Management
- Financial Dashboard
- System Monitoring
- KPI Reporting

## 13-Week Curriculum Breakdown

### Week 1: JavaScript Core + ES6+ Mastery (Foundation)
**Goal**: Master JavaScript fundamentals needed for React Native

**Key Topics**:
- Variables, Data Types, Operators (var, let, const)
- Control Flow (if/else, switch, loops)
- Functions (regular, arrow, higher-order)
- Arrays & Objects (methods, manipulation)
- ES6+ Features (destructuring, spread, rest, template literals)
- Async JavaScript (Promises, async/await, fetch)
- Error Handling
- TypeScript Introduction (type annotations, interfaces)

**CV Skills Covered**: JavaScript (ES6+), TypeScript basics

**Projects**: JavaScript exercises, API fetching practice, TypeScript conversion exercises

---

### Week 2: React.js Fundamentals (Web Foundation)
**Goal**: Learn React for Admin Dashboard development

**Key Topics**:
- React Components (functional components - modern approach)
- JSX syntax
- Props and State
- Event Handling
- Conditional Rendering
- Lists and Keys
- React Hooks (useState, useEffect, useContext, custom hooks)
- Component Lifecycle
- Forms in React
- TypeScript with React
- Styled Components / CSS-in-JS
- Material-UI components
- Tailwind CSS integration

**CV Skills Covered**: React.js, TypeScript, Styled Components, Material-UI, Tailwind CSS

**Projects**: Build React components with TypeScript, styled components, Material-UI dashboard layout

### Week 3: Node.js + Express + Backend APIs
