## 90DaysAJ Frontend – Plan & Schedule (Non-Destructive)

### What’s here
- Full React/Tailwind/Framer Motion dashboard UI for the 90-day Software Engineering journey.
- Horizontal discipline tabs (Frontend, Backend, Mobile, WordPress) with collapsible sections.
- Simple dashboard/roadmap/lesson views for non‑tech‑savvy users.
- Daily quiz and end-of-day practical assessment views.
- Gamification, achievements, motivation, reminders, time blocks, and focused implementation task manager.

### Daily schedule (containers only, curriculum untouched)
- Deep Learning (study): Mon–Fri 10:00am–12:00pm; Sun–Fri 3:00am–4:00am; Sun 2:00pm–3:00pm; Sat 2:00pm–3:30pm.
- Focused Implementation (build): Mon–Fri 8:00am–10:00am; Sun–Fri 4:00am–5:00am; Sun 3:00pm–4:00pm; Sat 3:30pm–5:00pm.

### Discipline rotation
- Sun–Fri (must cover all, in priority order): Frontend → Backend → Mobile (Flutter first) → WordPress.
- Saturday: WordPress only (both study and build).

### Sync rules
- Backend tasks align with current frontend work.
- Mobile integrates backend APIs.
- WordPress aligns with real-world patterns and freelancing/monetization.

### Progress & completion
- Progress only increments when lessons are explicitly marked complete.
- Daily quiz + practical assessment available per day; projects build on prior days.

### Where to run
- Dev server: from this folder `npm install` then `npm run dev` (Vite).
- Ensure `.env` (if any) stays outside git; `node_modules` are not tracked.
